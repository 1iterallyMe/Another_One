# Another_One

3D-головоломка / escape room от первого лица. Игрок заперт в белой комнате:
нажимает красные кнопки, собирает фрагменты кода, запускает генератор и
выбирается через зиплайн.

НТО 26/27, профиль «Разработка компьютерных игр», II отборочный этап,
блок «Программирование». Команда «Бурмалдята» (Talent ID 54266).

## Стек

- Unity **6000.3.10f1**, URP 17.3.0, Input System 1.18.0
- C#, всё в `Assembly-CSharp`
- Сцены: `Assets/Scenes/Amir.unity` (игра), `Menu_Scene`, `Credits_Scene`

## Запуск

1. Unity Hub → Add project from disk → эта папка (нужен редактор 6000.3.10f1).
2. Открыть `Assets/Scenes/Amir.unity` → Play.
3. Сборка: `File → Build Settings` → StandaloneOSX → Build.

Собранный билд и материалы блока лежат в `~/Desktop/NTO_Project`.

## Управление

WASD — движение, мышь — обзор, Space — прыжок, Left Shift — бег,
Left Ctrl — присесть, E — взаимодействие, F — использовать/бросить,
Esc — освободить курсор.
