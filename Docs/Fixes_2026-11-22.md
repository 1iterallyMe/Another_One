# Итерация 2 — генератор, масштабы моделей, именование

## FIX-01 — нельзя было поднять генератор

**Симптом:** игрок наводится на генератор, но взаимодействие не появляется.

**Настоящая причина (не физика):** на одном GameObject (`1983262584500687189`)
висят **два** `IInteractable` — `GeneratorController` (заправка) и `PickupObject`
(поднять). `PlayerInteractor.UpdateFocus` брал **первый** найденный компонент и,
если его `CanInteract` возвращал `false` (нет канистры в руках), объект целиком
считался неинтерактивным. Масса (`m_Mass: 10` при `maxCarryMass: 20`) никогда не
была препятствием.

**Что сделано:** `Assets/Scripts/Player/Interaction/PlayerInteractor.cs`
— добавлен `ResolveInteractable(Collider)`: сначала основной `IInteractable`,
затем fallback на `IPhysicsHoldable` на том же объекте. Без аллокаций
(два `GetComponentInParent`), поэтому безопасно для `Update`.

**Проверено (Play Mode `Amir`):**
- `ResolveInteractable(BoxCollider генератора)` → `PickupObject`
- `BeginHold` → `IsHolding=True`, `HeldMass=10`, `IsDraggingHeavy=False`,
  `PlayerSpeedMultiplier=1`
- `Release` → `IsHolding=False`
- Console: 0 error

**Побочный выигрыш:** то же исправление лечит любой объект с несколькими
интеракторами (канистра/розетки/провод).
