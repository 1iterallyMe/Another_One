## BUG-001 — зиплайн в `Amir` не двигался

**Причина:** `HasPower == false` (в инстансе `Amir` нет `generator`, а
`powerWithoutGenerator` был выставлен в `0` незакоммиченным WIP-изменением).
В `Alexander` баг не воспроизводился: там `generator` назначен scene-override'ом.

**Решение:** вариант **B** — override в инстансе, базовый префаб не меняется.

### Как воспроизвести проверку

1. `refresh_unity` (scope: assets).
2. Play `Amir`.
3. Найти `ZiplineRig` → `MarkAsInstalled()` + `ActivateOnCable()`.
4. Убедиться: `HasPower == true`; `MoveRoute(+1, 0.2f)` смещает объект по маршруту.
5. Для Y-режима: выставить `useCableRoute = false` (reflection) →
   `StartMoveAlongY(-1, minY)` → объект опускается к `minY`;
   `StartMoveAlongY(+1, maxY)` → поднимается к `maxY`.
6. Console: без error.
